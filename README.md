# Railway Track CAD

Animated top-down view of a railway yard with 5 tracks, multiple independent trains, a merged central station with common departure board, coastal promenade with coconut trees and sea. Pure HTML5 Canvas 2D rendering with retro CRT effects.

**Live Demo**: https://babubahir.github.io/railway-cad/

## Running

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
